# Security

This is a PS1 game port, so most bugs are just bugs. Crashes, broken songs, bad VRAM uploads, and cursed menu behavior belong in the normal issue tracker.

If you find something that could expose credentials, execute unexpected host-side code, poison the build/download process, or otherwise should **not** be posted publicly, use GitHub's private vulnerability reporting / security advisory flow if it is available for the repo.

If that option is not available, contact the maintainer privately through GitHub instead of posting secrets, tokens, private URLs, or exploit details in a public issue.

Please include the affected commit, file/path, reproduction steps, and what you think the impact is.
